# Counter App

A simple and beginner-friendly **Counter App** built using HTML, CSS, and JavaScript.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- ➕ Increase the counter
- ➖ Decrease the counter
- 🔄 Reset the counter to 0

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Use the buttons to increase, decrease, or reset the counter.

## Project Structure

```text
Counter App/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Purpose

This project was created to practice **JavaScript DOM manipulation and event handling**.
